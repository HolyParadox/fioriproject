# 💼 SAP Fiori Travel Expenses App

This is a simple **SAPUI5/Fiori application** for tracking travel expenses. It allows users to input individual expense entries (date, description, amount, currency, and category) and view them in a table below.

> 💡 Built using SAPUI5, JSONModel, and Fiori 3 theme — no backend required!

---

## 🔧 Features

- Input form for travel expenses
- Auto-binding to JSON model table
- Dynamic table rendering
- Popup dialog (WIP)
- CSS styling via external stylesheet
- **Future-ready** for backend connection (localStorage logic included but currently deactivated)

---
 📝 Notes 
 
 > This app uses demo data only.

 > No real expense submission or persistence yet (for privacy and security).

 > LocalStorage logic is included but commented/disabled.
 
 > File upload popup is currently implemented but needs polish.
